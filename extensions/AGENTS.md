# Working in the spatial interface example

- Read README.md. Use Node 24, keep the exact dependencies and lockfile, then run `npm ci`, `npm run check`, `npm run build` and `npm run dev` here.
- This project is optional. Running the parent starter does not require installing this directory's dependencies.
- Use the real public Work. Check visible hotspot output, measurement and camera/caption playback in a browser; a successful build alone is not rendering evidence.
- Keep one Five scene per container, clean up plugins/player/listeners on replacement, and use actual Work coordinates and panorama identifiers.
- Do not add credentials, Team API calls, Live, RTC or permission requests. Never read or copy the parent `.env` into this browser-only project.
- Preserve the compatible SDK/React/Three versions and the targeted protobufjs override. Report an error rather than forcing incompatible dependencies or replacing the real scene with an image.
